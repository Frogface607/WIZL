# WIZL Content Workspace

Each publishable post lives in its own folder with its source material, manifest, caption, and final assets.

## Status Source

Use [publish-queue.md](../publish-queue.md) as the only current publishing queue. Older dated folders are experiments and are not approved automatically.

## Required Files

Depending on format:

- `manifest.json`
- `caption.md`
- prompt files
- source note or URL for factual content
- final image, carousel slides, or edited reel
- cover image for video
- QA contact sheet for carousels

## Workflow

1. Start from the current content plan.
2. Create a manifest with an active factory recipe.
3. Review the claim and save its source.
4. Generate the visual.
5. Review character consistency, text, rights, platform policy, and local law.
6. Render and verify the final file.
7. Add it to the publish queue only after human approval.
8. Record the live link and metrics after publishing.

No folder is publish-ready merely because generation completed. Shop promotion, purchase cues, celebrity likenesses, invented endorsements, and unsourced effects are blocked.
