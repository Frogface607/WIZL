## Architecture

### Hybrid strategy

```
                  ┌─────────────────────────┐
                  │  Next.js 16 app (web)   │
                  │  static export → "out/" │
                  └──────────┬──────────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
         ┌────▼────┐    ┌────▼────┐   ┌─────▼─────┐
         │  Web    │    │ Android │   │ iOS PWA   │
         │ Vercel  │    │Capacitor│   │ (Safari + │
         │         │    │ bundled │   │ Home      │
         │         │    │  shell  │   │ Screen)   │

                             │              │
                             └──────┬───────┘
```

One codebase, three surfaces. **Android ships a bundled static shell with live API calls — NOT a thin webview wrapper.** iOS users install the PWA via Safari → Add to Home Screen.

### Capacitor setup — bundled shell, live data

**Reviewer round 1 critical fix:** Google Play automatically fingerprints pure `server.url` webview wrappers and rejects under "Webview Spam" / "Minimum Functionality". We bundle the static shell instead.

- **Capacitor 7** (verified current as of May 2026 — pre-flight Day 0 confirms compatibility with Next.js 16)
- Android only this sprint (no iOS Capacitor project)
- New directory at repo root: `android/` (generated by `npx cap add android`)
- `capacitor.config.ts`:
  - `appId: "space.wizl.app"` (reverse DNS)
  - `appName: "WIZL"`
  - `webDir: "out"` — **Next.js static export bundled into the APK**
  - NO `server.url` in default config (only used in dev for hot reload)
  - All API calls go to `https://wizl.space/api/*` and Supabase via fetch — live data

#### Two-build configuration (Next.js 16 critical)

`next export` as a standalone command **does not exist in Next.js 16** (removed in v14). Instead, `output: 'export'` in `next.config.ts` makes `next build` emit `out/` directly. Critical: **`output: 'export'` is incompatible with API Route Handlers** — they get stripped from the bundle.

We therefore ship **two builds from one codebase** via environment variable:

```ts
// next.config.ts
const isCapacitor = process.env.BUILD_TARGET === 'capacitor';
export default {
  output: isCapacitor ? 'export' : undefined,
  // ...rest
};
```

```jsonc
// package.json scripts
{
  "build": "next build",                              // Vercel deploy: includes /api/* routes
  "build:capacitor": "BUILD_TARGET=capacitor next build", // Capacitor: static export, no /api/*
  "cap:sync": "pnpm build:capacitor && npx cap sync android",
  "cap:android": "pnpm cap:sync && npx cap build android"
}
```

| Surface | Build cmd | API routes | Output |
|---|---|---|---|
| Web (wizl.space, Vercel) | `next build` | Bundled | `.next/` Vercel deploys |
| Capacitor Android | `BUILD_TARGET=capacitor next build` | **Excluded** | `out/` bundled into APK |

The Capacitor APK calls `https://wizl.space/api/push/register` over the network — same backend, just no co-located code in the APK. This is normal, secure, and explicitly recommended by Capacitor docs.

- Static shell guarantees: cold start works offline, Play "Minimum Functionality" cleared, content updates via API only (no app re-publish needed)

- Native plugins (minimum viable):
  - `@capacitor/push-notifications` — FCM
  - `@capacitor/share` — native share sheet
  - `@capacitor/app` — deep linking, lifecycle hooks
  - `@capacitor/splash-screen` — branded splash on cold start
  - `@capacitor/preferences` — local key-value storage
  - `@capacitor/status-bar` — match brand colours
  - `@capacitor/browser` — open external links via Custom Tabs
  - `@sentry/capacitor` — crash reporting (reviewer concern)
- Native bridge layer in `src/lib/native.ts`:
  - `isNative()` — detect Capacitor runtime
  - Wrappers around plugins that no-op gracefully on web

### Removing Russian locale

Босс confirmed (2026-05-15): RU is out of WIZL entirely. He uses the app in English himself.

Why: legal risk under КоАП РФ 6.13 "пропаганда наркотиков" if WIZL is reachable to Russian-speakers with Russian-language cannabis content. The country-block in Google Play does not cover web (wizl.space), so the language-layer protection is what matters.

**Full audit scope (Day 0 task — verify before Day 1 code touches anything):**

1. **Source files** — `rg '[\p{Cyrillic}]' src public messages supabase` — every match is a finding. Common likely locations:
   - `messages/ru.json` (delete)
   - `messages/en.json` (look for accidental RU strings in fallback)
   - `src/data/strains.ts` — strain `description`, `lore`, `funFact` fields may have RU content
   - `src/data/shops.ts` — shop names/cities for Russia-located shops (also: remove RU-located shops entirely)
   - `src/app/[locale]/**/*.tsx` — hardcoded RU strings outside i18n
   - OG meta in `src/app/layout.tsx` or per-page metadata
   - `public/manifest.json` (lang field, description)
   - `README.md`, `public/sitemap.xml` (if generated with RU URLs)

2. **Supabase DB rows** — SQL audit:
   ```sql
   -- Find Cyrillic in strain text columns
   select id, name from strains where description ~ '[А-Яа-я]';
   select id, name from strains where lore ~ '[А-Яа-я]';
   -- Repeat for any other text columns: shops, achievements, etc.
   ```
   Either translate found rows to EN, or remove. List rows in a migration commit.

3. **i18n config**:
   - Delete `messages/ru.json`
   - `src/i18n/routing.ts` — remove `ru` from locales, `defaultLocale: 'en'`
   - `src/i18n/request.ts` — verify no RU branches
   - `public/manifest.json` — `"lang": "en"`, no per-locale variants

4. **Redirect for old `/ru/*` URLs** — since the Vercel web build still uses Next.js (not static export), use Next.js middleware OR `vercel.json` redirects. **The static-export Capacitor build does not need this — `out/` will not contain `/ru/*` routes after the locale is removed.**
   ```json
   // vercel.json (web only)
   {
     "redirects": [
       { "source": "/ru", "destination": "/en", "permanent": true },
       { "source": "/ru/:path*", "destination": "/en/:path*", "permanent": true }
     ]
   }
   ```

5. **Search engines** — `robots.txt` Disallow `/ru/`, file a Google Search Console removal request for any indexed RU pages (cleanup, not blocker).

### iOS PWA install flow

Component: `src/components/IosPwaInstallPrompt.tsx`
Detection: `src/lib/platform.ts`

```ts
// platform.ts (high-level shape)
export function isIOS(): boolean {
  // userAgent includes 'iPad'/'iPhone'/'iPod', OR
  // iPadOS 13+ desktop mode: platform === 'MacIntel' AND maxTouchPoints > 1
}
export function isSafari(): boolean {
  // userAgent has 'Safari' AND NOT 'CriOS' (Chrome on iOS) AND NOT 'FxiOS' (Firefox)
}
export function isInAppBrowser(): boolean {
  // Line, FB, IG, WeChat in-app browsers — Add-to-Home doesn't work there
}
export function isStandalone(): boolean {
  return ('standalone' in navigator && (navigator as any).standalone === true)
      || window.matchMedia('(display-mode: standalone)').matches;
}
export function shouldOfferIosInstall(): boolean {
  return isIOS() && !isStandalone() && !recentlyDismissed();
}
```

**Reviewer round 1 concerns addressed:**
- iPad Safari 13+ desktop-mode detection via `maxTouchPoints`
- `navigator.standalone` existence check before access
- Chrome/Firefox on iOS detected separately — they cannot install PWA, show different message: "To install WIZL on iPhone, open this page in Safari"
- In-app browser detection (Line/FB/IG/WeChat) — common QR-from-shop entry point — show "Open in Safari" CTA, no install steps

Trigger logic:
- Show modal after age gate passes, IF `shouldOfferIosInstall()`
- Always-available entry point: "Install on iOS" link in profile/menu (mobile only)
- Dismissal stored in `localStorage` with 3-day cooldown key `wizl-ios-install-dismissed-at`

Modal contents (visual assets stubbed, real ones from sibling session):

- Step 1: "Tap the Share button" + arrow pointing down (Safari share is in bottom bar)
- Step 2: "Scroll and tap Add to Home Screen"

## Native features (Sprint 1 minimum bar)

### 1. Push notifications (Android only this sprint)

**Reviewer round 1 critical fix:** push registration is gated on sign-in. Anonymous users do NOT register tokens. This keeps the Data Safety form simple ("device IDs collected only for signed-in users for engagement reminders").

- Firebase project: `wizl-prod`, FCM enabled
- Supabase migration:
  ```sql
  create table device_tokens (
    id uuid primary key default gen_random_uuid(),
    user_id uuid not null references auth.users(id) on delete cascade,
    token text not null unique,
    platform text not null check (platform in ('android','ios','web')),
    created_at timestamptz default now(),
    last_seen_at timestamptz default now()
  );
  create index on device_tokens (user_id);
  ```
  Note: `user_id NOT NULL` — enforces sign-in requirement.
- API route: `src/app/api/push/register/route.ts` — accepts `{ token, platform }`, requires authenticated session, upserts for current user
- Permission timing: NOT on app open. Trigger after **first successful checkin** (contextual prompt: "Want Wizl to remind you next time?"). Higher grant rate, better Play review optics.
- v1 trigger: **"Time to log a checkin?"** — fire 6 hours after last open, max 1/day. Cron Edge Function `cron-checkin-reminder` runs hourly, finds eligible signed-in users with registered tokens, sends FCM.
- Notification text (Босс to confirm at review): "Wizl is wondering — how was your session?"
- Data Safety declaration: "Device or other IDs — collected, not shared, optional, for app functionality (push notifications)"

### 2. Offline cache + crash reporting

- **Static shell already bundled** (Capacitor `webDir: "out"`) — no service worker needed for the shell itself
- Service worker (hand-rolled, light) for data-layer caching:
  - **Strain index** (`/api/strains`): stale-while-revalidate, max 7 days
  - **Strain detail top 50**: pre-cached on first install (background fetch after age gate)
  - **AI chat empty state**: cached so offline first-load doesn't white-screen
  - **User's own checkins**: mirror to IndexedDB on every fetch
- Offline banner: subtle "you're offline — showing cached strains" on strains page when `navigator.onLine === false`
- **Sentry Capacitor SDK** integrated Day 4. Configure with separate DSN for mobile-vs-web. Sample rate 100% Sprint 1 (low traffic, learn fast).
